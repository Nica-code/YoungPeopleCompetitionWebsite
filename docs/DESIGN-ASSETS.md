# Locally hosted design assets

- Display font: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond), from the Google Fonts project. `app/fonts/OFL.txt` contains its SIL Open Font License. The font is bundled locally with the site; the page does not request a font from Google.
- Interface icons: [Phosphor Icons](https://phosphoricons.com/), original regular-weight SVG files from the [official repository](https://github.com/phosphor-icons/core). `public/icons/LICENSE` contains the MIT license.
- Institutional identities: the approved files in `public/partners/` are retained as supplied. The Marshall, Huntington Symphony Orchestra, and Cabell County Schools logos are displayed without recoloring or distorting their proportions.
- The design exploration images are references only. The deployed interface is HTML, CSS, local font files, original institutional logos, and original icon assets.
